# Every screen, in journey order

[Back to the README](../README.md)

The seller screens are the real app code, run with demo data (LOJA DEMO, DEMO CASA, Rafael Demo) and no database or network. The admin screens are the real admin panel connected to a test server that holds only fictional data. The HQ screens are the HQ's own demo mode, with a "simulated data" banner. The newsroom and Instagram images are Velox's own public pages and posts.
